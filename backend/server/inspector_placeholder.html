Inspector SPA not built

The backend embeds the inspector single-page app at compile time, but the frontend assets weren't present when this binary was built. Build them with: 

cd backend/inspector-ui
npm install
npm run build

then rebuild and restart the backend: 

cargo build -p encrypted-spaces-backend-server

Tip: don't apt install node-typescript — that package is older than 5.0 and will reject this project's tsconfig.json. The bundled TypeScript from npm install is the right one.
